📊 Week 1 Internship Project – Exploratory Data Analysis (EDA)

This repository contains my Week 1 Internship Project completed during my internship at Aptura Tech Solutions.

The project focuses on performing Exploratory Data Analysis (EDA) on the Netflix Titles dataset using Python. The objective was to understand the dataset, clean missing values, remove duplicate records, analyze important features, and visualize insights through charts.

🚀 Project Objectives
	•	Load and explore the dataset
	•	Understand the structure of the data
	•	Handle missing values
	•	Remove duplicate records
	•	Perform basic statistical analysis
	•	Analyze categorical features
	•	Create meaningful visualizations
	•	Export the cleaned dataset

🛠️ Technologies Used
	•	Python
	•	Pandas
	•	NumPy
	•	Matplotlib
	•	Jupyter Notebook

📂 Dataset

The project uses the Netflix Titles Dataset, which contains information about movies and TV shows available on Netflix, including:
	•	Title
	•	Type
	•	Director
	•	Cast
	•	Country
	•	Release Year
	•	Rating
	•	Duration
	•	Genre

📈 Analysis Performed
	•	Dataset overview (shape, columns, and information)
	•	Missing value handling
	•	Duplicate record removal
	•	Data cleaning
	•	Frequency analysis of content types
	•	Country-wise content analysis
	•	Rating distribution
	•	Data visualization using bar charts
	•	Exporting the cleaned dataset

📌 Learning Outcomes

Through this project, I gained hands-on experience with:
	•	Data cleaning techniques
	•	Exploratory Data Analysis (EDA)
	•	Working with real-world datasets
	•	Data visualization using Matplotlib
	•	Preparing datasets for further analysis and machine learning
